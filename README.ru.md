# Genesis 🧬

---

### Genesis - мой школьный проект о моделировании симуляции частиц.  
На проект меня вдохновили различные клеточные автоматы и видео на YouTube о подобных симуляциях.

### В Genesis есть 2 режима:
- Стандартный, где частицы притягиваются или отталкиваются друг от друга в зависимости от матрицы взаимодействий
- Комплексный, где в матрице взаимодействий присутствуют комплексные числа, которые задают частицам вращение, и позволяют делать ещё более разнообразные симуляции

### Управление:
Нажмите Tab, чтобы открыть настройки симуляции
Q, E - меняет количество типов частиц
R - рандомно распределяет частицы по экрану
G - генерирует случайные правила симуляции
F - изменяет цвета разных типов частиц на рандомные

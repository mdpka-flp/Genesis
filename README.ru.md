# Genesis 🧬

---

### Genesis - мой школьный проект о моделировании симуляции частиц.  
На проект меня вдохновили различные клеточные автоматы и видео на YouTube о подобных симуляциях.

### В Genesis есть 2 режима:
- Стандартный, где частицы притягиваются или отталкиваются друг от друга в зависимости от матрицы взаимодействий
- Комплексный, где в матрице взаимодействий присутствуют комплексные числа, которые задают частицам вращение, и позволяют делать ещё более разнообразные симуляции

Стандартный режим дополнительно может считаться на видеокарте (см. ниже). Переключение
режима в окне настроек сохраняет текущие правила и цвета, поэтому одно и то же правило
можно сравнить в стандартном и комплексном режимах.

### 🎮 Ускорение на GPU (необязательно)
В Genesis есть GPU-бэкенд (ILGPU + OpenCL/CUDA). Это бонус, а не требование: если
подходящего устройства нет, приложение тихо откатывается на CPU и пишет в оверлее
`Mode: CPU fallback`.

Что нужно поставить:
- **Windows + NVIDIA** — ничего, CUDA приезжает с драйвером.
- **Windows + AMD** — ничего, OpenCL приезжает с драйвером Adrenalin.
- **Linux + NVIDIA** — только проприетарный драйвер.
- **Linux + AMD** — runtime ROCm OpenCL (по умолчанию он **не** установлен):
  - Arch / Manjaro: `sudo pacman -S rocm-opencl-runtime`
  - другие дистрибутивы: пакет «ROCm OpenCL» из репозиториев или с сайта AMD.
  Драйвер Rusticl из Mesa не подходит: он отдаёт OpenCL C 1.2 без generic address
  space, который требует ILGPU, и карта отбрасывается.
- **macOS** не поддерживается (у ILGPU нет Metal-бэкенда).

Проверить, какой бэкенд реально используется, можно по консольному логу при старте
или по строке `Mode: ...` в оверлее.

### ⬇️ Скачать
Готовые сборки одним файлом лежат на странице [Releases](https://github.com/mdpka-flp/Genesis/releases):
- `Genesis.exe` — Windows x64, просто запустить;
- `Genesis` — Linux x64, после скачивания `chmod +x Genesis` и запустить.

Больше ничего устанавливать не нужно: .NET и нативные библиотеки упакованы внутрь
исполняемого файла (кроме необязательного OpenCL-runtime, о котором выше).

### Управление:
Нажмите Tab, чтобы открыть настройки симуляции
Q, E - меняет количество типов частиц
R - рандомно распределяет частицы по экрану
G - генерирует случайные правила симуляции
F - изменяет цвета разных типов частиц на рандомные

Цвета отдельных типов частиц задаются в окне настроек. Раздел «Random ranges» внизу
этого окна задаёт границы, из которых берутся случайные значения при генерации правил.
